# Community Canvas

Build a complete, modern, emotionally engaging nonprofit landing page for:

KOMMUNITY HOUSE

Use the attached Kommunity House logo as the primary logo throughout the website. Do not redesign or alter the logo. Build the visual identity around the existing black, white, and warm gold/tan colors from the logo.

IMPORTANT:

This should feel like a real, established community organization — NOT a generic nonprofit template.

The website should communicate:

COMMUNITY • OPPORTUNITY • UNITY • EDUCATION • ENTREPRENEURSHIP • PARTICIPATION

Create a premium, welcoming, community-focused design with strong typography, beautiful photography, subtle animations, generous spacing, and clear calls to action.
